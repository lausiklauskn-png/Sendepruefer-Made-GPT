# Sende-Prüfer

Kundendaten verdecken, bevor eine KI sie sieht. Eine Seite, die Namen, Nummern und Beträge durch Platzhalter ersetzt, den Text kopiert oder an die KI Ihrer Wahl schickt und die Antwort mit den echten Angaben zurückgibt. Sie läuft vollständig im Browser.

**Öffnen:** https://lausiklauskn-png.github.io/Sende-Pruefer/
